# lacuartapiel.com

Web de **La Cuarta Piel**, migrada desde Cargo en noviembre de 2026.

- `docs/` — la web publicada (GitHub Pages sirve esta carpeta). Cada proyecto es un archivo `slug.html`; las imágenes están en `docs/img/` y los estilos comunes en `docs/style.css`.
- `tools/` — script con el que se generó la web a partir del contenido exportado de Cargo (`data.json`, `pins.json`). Ya no hace falta para editar: los cambios se hacen directamente en `docs/`.
